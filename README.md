# C-practices

This repository is a personal archive where I store my C programming practices and exercises.

The main purpose of this repository is to keep track of my progress while learning the C language, from its fundamental concepts and core principles to more advanced topics.

Here I will upload the programs, experiments, and challenges that I complete throughout my journey of understanding how C works and how software interacts closer to the system.

- Pointers
- Memory management
- Structures
- File handling
- Data structures

This repository represents my progress, improvements, and the knowledge I gain while learning one of the most important programming languages.
